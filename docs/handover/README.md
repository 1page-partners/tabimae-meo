## 目的と現在地

対象は施設のマーケティング担当者、担当コンサルタント、運営管理者です。施設ごとの口コミ対応・Google投稿・集客状況の確認・AI相談を一か所で行い、月次MEOマガジンで具体的な改善行動を届けます。MEOスコアはアプリ独自の指標で、Googleの公式評価や順位ではありません。

主要機能の画面と処理は実装されていますが、全機能が実サービスで確認済みの完成品ではありません。Google実認証、AI生成、実メール送信、自動生成の初回実行は過去資料でも未確認です。さらに今回のコード調査で認可・初期構築上の懸念を確認しました。運用拡大前に [未完了事項](BACKLOG.md) のP0/P1を確認してください。

| 3ロール認証、施設・担当者・ユーザー管理 | 実装あり。施設所属とRLSで制御。認可の個別懸念あり |
